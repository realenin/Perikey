# 威胁模型（Threat Model）

> 聚焦使用者 Kali 实测中观察到的核心威胁：**设备密度越高，抓包成功率越高，单 PSK 被爆则全网失守**。

## 1. 攻击者分类

| ID | 攻击者 | 能力 |
|----|--------|------|
| A0 | 外部被动 | 仅能抓包（含四次握手），未接入网络，读不到 LAN 流量 |
| A1 | 外部主动 | A0 + 可发 deauth 强制重连、重复抓包 |
| A2 | 入网内鬼 | 已通过旧 `K` 接入，能读 LAN 内明文 |
| A3 | 伪造设备 | 未注册、无 `DSecret`，试图混入 |

## 2. 密度效应（使用者观察的机制解释）

单 PSK 模型下，网络上任意一台设备的握手包都可爆破出**全网共用**的 `K`。设每次握手被捕获概率为 `p`，设备数 `N`，则至少捕获一个握手的概率：

```
P(capture ≥ 1) = 1 − (1 − p)^N
```

`N` 越大（使用者家中 25+ 设备、约百台智能电器），`P` 越趋近 1——即使用者所言「接入设备越多，抓包成功率越高」。**PeriKey 的价值在于让每一次成功抓包的时间价值骤降**：轮换后旧握手包作废，攻击者须每个周期重新抓包+爆破。

## 3. 各攻击者下的缓解评估

| 攻击者 | PeriKey 是否缓解 | 说明 |
|--------|------------------|------|
| A0 外部被动 | ✅ 强缓解 | 读不到 LAN → 拿不到预约定下发的 `K'`；旧握手包轮换后作废 |
| A1 外部主动 | ⚠️ 部分 | deauth 可反复生成握手并爆破 `K`（若 `K` 弱）；但仅当前周期有效，轮换后需重来。建议配合强 `K` 与 WPA3-SAE |
| A2 入网内鬼 | ✅（需注册） | `K'` 经 `DSecret_i` 加密，持旧 `K` 也读不到；轮换强制重认证将其踢出 |
| A3 伪造设备 | ✅ | 无 `DSecret` → 收不到 `K'`；若靠爆破 `K` 混入，轮换即被清退 |

## 4. 未被缓解 / 残余风险

1. **弱主密码 `K`**：若 `K` 过弱，A1 可在单周期内爆破成功。→ 建议 `K` 足够强 + 启用 WPA3-SAE（抗离线字典攻击）。
2. **未注册设备（无 `DSecret`）的明文下发路径**：对 A2 不保密。→ 推广阶段 0 注册覆盖。
3. **`DSecret_i` 设备端存储**：低端 IoT 无安全存储，可能被提权读取。→ 退化为「重置后 2FA 重新授权」。
4. **错过的设备**：预约定时离线则收不到 `K'`。→ 阶段 5 容错处理。
5. **已植入后门**：攻击者轮换前已控设备并植入后门，属本系统职责之外。

## 5. 与 WPA3 的叠加

PeriKey **不替代** WPA3-SAE，而是叠加在其上：

- WPA3-SAE 已抗离线字典攻击、提供前向保密 → 直接削弱 A0/A1 的爆破效率。
- PeriKey 的旋转 + 自动分发解决「定期换密的人工成本」与「设备密度助攻」→ 纵深防御。

建议部署目标：**WPA3-SAE（或 sae-mixed）+ PeriKey 自动轮换 + 老设备 PPSK 长密码**。
