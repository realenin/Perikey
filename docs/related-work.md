# 已有工作对比（Related Work）

> 使用者提到「没有类似案例也算创新」。经调研，**存在明确先例**，故本项目不做「全球首创」宣称，而是诚实定位增量价值。下表逐条对比。

## 1. Private PSK（PPSK）/ `hostapd` `wpa_psk_file`

- **是什么**：OpenWrt `hostapd` 原生能力，允许在**同一 SSID** 下为不同 MAC 配置不同 PSK。
- **代表实现**：
  - `fakuivan/hostapd-slppsk`（GitHub，2023）：无数据库，按 `SHA256(MasterPassword‖MAC)` 派生每设备 PSK，支持 VLAN 绑定。
  - RADIUSdesk PPSK：通过文件或 RADIUS 下发每设备 PSK。
- **与本项目的异同**：
  - 同：每设备独立密钥、同 SSID、无需 RADIUS。
  - 异：slppsk **无轮换/epoch 概念、无 2FA 门控管理平面、无安全分发通道、依赖 MAC（受随机化影响）**。PeriKey 在这些维度做加法。
- **启示**：证明「同 SSID 每设备密钥」在消费硬件上**已可行**，是我们方案的地基。

## 2. WPA3-Enterprise / 802.1X + RADIUS

- **是什么**：企业级每设备**证书/凭证**认证，EAP-TLS 双向认证，会话密钥每次派生。
- **能力**：天然满足「每设备独立 + 前向保密 + 可撤销」。
- **与本项目的异同**：
  - 同：每设备隔离、可撤销。
  - 异：**消费级路由器几乎不支持**（ASUS 官方明确消费路由不支持 WPA3-Enterprise）；需要 RADIUS 服务器与客户端证书；**大量 IoT 设备不支持 802.1X**。
- **启示**：是「正确但门槛高」的路线。PeriKey 选 PPSK 为主路线正是为了避开该门槛；802.1X 作为高安全可选路线。

## 3. Wi-Fi DPP / EasyConnect（Device Provisioning Protocol）

- **是什么**：Wi-Fi 联盟标准，用**公钥密码**替代共享密码完成设备入网（扫 QR/NFC），支持 **Reconfiguration**（DPP v2 起）用已下发的 `netAccessKey` 重配置设备。
- **能力**：无密码入网、设备级身份、可重配置（接近我们的轮换思想）。
- **与本项目的异同**：
  - 同：设备身份密钥、免共享密码、可重配置。
  - 异：**消费路由普遍不支持 DPP**；且 **2025 DEF CON 33《Breaking Wi-Fi Easy Connect》** 披露严重问题：
    - QR 引导仅认证 AP 一侧，任意扫码设备即可获得完整网络凭证；
    - DPP Envelope 用 PBKDF2 口令加密，可被离线字典爆破出 **PPK（Privacy Protection Key）**；
    - PPK 是**静态、不可撤销**的网络级单点失效——改 WPA 密码也无法轮换它。
- **启示**：DPP 的「重配置」思想值得借鉴，但其「单一主密钥（PPK）掌控全网」是**反模式**，PeriKey 必须规避（采用每设备独立 DIK + 可撤销注册表）。

## 4. WPA3-SAE（WPA3-Personal）

- **是什么**：用 SAE（Dragonfly）替换 WPA2 的 PSK 四次握手。
- **能力**：抗离线字典攻击（截获握手无法破密码）、前向保密。
- **与本项目的异同**：
  - 同：都提升「抓包」场景下的安全性。
  - 异：SAE **仍是全网共享一个密码**；不解决「单设备沦陷→全网通用密钥泄露」与「定期轮换 + 免配置」。
- **启示**：PeriKey 应运行在 **WPA3-SAE 之上**作为纵深防御，而非替代它。

## 5. Matter / Thread 设备入网

- **是什么**：智能家居的**安全 commissioning** 协议，用带外二维码/口令完成设备与枢纽的认证密钥交换。
- **启示**：其「一次性带外引导建立长期信任，之后自动轮换」的范式，与 PeriKey 的「注册→安全分发→轮换」结构高度一致，可作为 UX 参考。

## 6. 创新边界总结

| 能力 | PPSK | 802.1X | DPP | WPA3-SAE | **PeriKey** |
|------|------|--------|-----|----------|-------------|
| 每设备独立密钥 | ✅ | ✅ | （凭证级） | ❌ | ✅ |
| 周期自动轮换 | ❌ | ✅(重认证) | ✅(重配置) | ❌ | ✅ |
| 免逐台配置 | 部分 | ❌(需证书) | ✅ | ✅ | ✅ |
| 使用者 2FA 门控 | ❌ | ❌ | ❌ | ❌ | ✅ |
| 消费级 OpenWrt 可落地 | ✅ | ❌ | ❌ | ✅ | ✅ |
| 抗 MAC 随机化（用 DIK） | ❌(靠MAC) | ✅ | ✅ | n/a | ✅ |

**定位**：PeriKey = PPSK 的「每设备密钥地基」+ DPP 的「轮换/重配置思想」+ 一个**消费级、2FA 门控、自动化的管理层**。协议不新，但「让普通家庭用户用得上」这一层是实空白，即本项目的立身之本。
