# PeriKey 参考原型（Prototype）

零依赖（仅 Python 标准库）的端到端演示，证明使用者想法的可行性。

## 运行

```bash
cd prototype
python3 demo.py
```

## 演示覆盖

1. 初始化网络（主路由 + 普通设备 + 老设备）。
2. 使用者经 2FA 设置新密码 `K'`。
3. **换密前预约定（PRA）**：用每台设备的 `DSecret` 加密下发 `K'`，化解鸡生蛋。
4. 路由器应用新密码，设备自动重连（无需逐台操作）。
5. 威胁 A：外部被动攻击者（仅抓旧握手包、不在网内）拿不到 `K'`。
6. 威胁 B：入网内鬼（持旧 `K`、在 LAN 内、无 `DSecret`）无法解密 `K'`。
7. 对照：未注册设备走明文下发时内鬼可读到 `K'`，说明注册加固必要。
8. 老设备独立长密码与主密码隔离。
9. 二次轮换后旧密码失效（前向隔离）。
10. 密度效应：设备越多，抓包成功率越高（印证使用者 Kali 观察）。

## 重要免责

`crypto_core.py` 使用 **SHA-256 密钥流**仅为演示协议流程，**非生产级加密**。
真实实现 MUST 使用 `HKDF-SHA256` + `AES-256-GCM`（见 `../docs/protocol.md` §9）。
